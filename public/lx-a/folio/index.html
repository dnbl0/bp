The brief

Everything that happens after login.

I redesigned the entire authenticated experience — dashboard, garage, Encore benefits, profile and concierge — into one consistent member journey with clear IA, reusable patterns and production-ready interaction behaviour.

Rather than hand over static mockups, I designed each decision and then built it as a working React prototype, so behaviour, edge cases and final UX quality could be reviewed in a real interface — a shared reference for product, content and engineering conversations.

Clearer UX, stronger delivery confidence, faster handoff.
Design system

One source of truth, primitive to pixel.

I built and maintained the token structure in Figma and mapped it to React UI components, so the system could scale with fewer visual regressions. The same tokens are documented in a 132-story Storybook, ready for handoff.

Accessibility

Designed to be used by everyone.

Accessibility was a constraint from the first token, not an audit at the end. Every story runs axe via Storybook's a11y addon — and this case study holds the same bar.

01
◑

WCAG AA contrast

Secondary text was lifted from #6e727e to #9499a1 so it clears 4.5:1 on raised surfaces. Foreground, accents and states are all AA-checked.

02
⤿

Reduced motion

Every reveal, parallax, autoplay video and transition stands down under prefers-reduced-motion — in the product and on this page.

03
⌨

Full keyboard path

⌘K command palette with arrow/enter/esc, focus-trapped flyouts that return focus on close, visible focus rings, and a skip link.

04
⊕

Semantics & ARIA

Native landmarks, role="dialog", switch, tablist, aria-current nav and aria-live toasts — announced correctly.

05
⊙

Comfortable targets

Touch targets meet the 44px minimum, with generous spacing on the mobile drawer and carousels for thumb reach.

06
✓

Automated + manual

axe-core on every Storybook story catches regressions; manual screen-reader and keyboard passes catch what automation can't.
