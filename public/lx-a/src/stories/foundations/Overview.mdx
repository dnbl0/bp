# Foundations

Foundations are the atomic decisions every other component inherits — the
colour, type, space and motion the brand operates on. Every component you
see in this Storybook resolves through tokens declared in
`src/styles/tokens.css`.

## Why tokens

- **Single source of truth** — change a value once and every consumer
  updates.
- **Theme-aware** — light and dark themes are token overrides, not separate
  stylesheets.
- **Predictable** — sizing, spacing and tracking snap to a small set of
  scales so the product feels coherent.

## Where to find things

- **Colour** — palette, semantic roles, scrims, tier identity.
- **Typography** — display vs body face, type scale, tracking.
- **Spacing** — the `--space-1..11` scale used for gap, padding, margin.
- **Radii** — `--radius-sm | md | pill`.
- **Shadows** — elevations and vehicle render shadows.
- **Motion** — eases, durations and the reveal/typing animations.
- **Tracking** — letter-spacing scale for uppercase eyebrows and chips.
- **Icons** — the inline SVG set, sized via the `width`/`height` props.

If you need a value that doesn't fit one of these scales, default to "no" —
either find the nearest token, or propose a new one in the token file.
